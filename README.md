## Project overview

| Item | Details |
| --- | --- |
| Application Type | Mobile |
| Primary Platform | Android / iOS |

Banyak masyarakat merasa kebingungan dan tidak memiliki akses langsung terhadap informasi atau bantuan hukum ketika dihadapkan pada situasi sengketa, surat peringatan, atau kontrak kerja. AMAN hadir untuk mendemokratisasi akses hukum dengan cara memungkinkan pengguna mengunggah dokumen hukum mereka dan mendapatkan analisis seketika mengenai hak, risiko, dan langkah selanjutnya yang dapat diambil menggunakan bahasa yang mudah dipahami.

## Key features

| Feature | What the user can do |
| --- | --- |
| **Legal Situation Checker** | Mengunggah foto atau PDF dokumen hukum untuk dianalisis oleh sistem secara instan. |
| **Analisis Indikator Hukum** | Mendapatkan ringkasan indikator Hak, Risiko, Keuangan, dan Langkah Tindakan. |
| **Panduan Hukum** | Membaca artikel dan panduan hukum praktis terkait ketenagakerjaan, pinjaman, dll. |
| **Kamus Hukum** | Mencari istilah-istilah hukum yang rumit beserta terjemahan bahasa awamnya. |

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

*   Flutter SDK installed on your machine.
*   An editor like VS Code or Android Studio.

### Installation

1.  **Clone the repo**
    ```sh
    git clone https://github.com/USERNAME/aman.git
    ```
2.  **Navigate to the project directory**
    ```sh
    cd aman
    ```
3.  **Install dependencies**
    ```sh
    flutter pub get
    ```
4.  **Run the app**
    ```sh
    flutter run
    ```
